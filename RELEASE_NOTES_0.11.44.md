# WeTongbu 0.11.44

- New Sync Center in the right sidebar: one place for sync status, a "Sync now" button, items that need your decision (conflicts, deletions waiting for confirmation), the recycle bin, your devices and clip status. The status bar now shows a single WeTongbu item that opens it.
- Recycle bin: files deleted from a synced Vault can be restored for 30 days. Restoring puts the file back at its original path, or next to it if that path is already taken; it never overwrites an existing file.
- Settings are grouped into Clipping, Sync, Account and Advanced (collapsed by default). Before turning on Vault sync, the plugin shows how many files and how much data this device will upload.
- New installs sync deletions automatically. Existing installs keep their current choice, including "review each deletion".
- Removed settings for features that were already retired (self-hosted storage and recovery codes).
