# WeTongbu 0.11.43

- The plugin no longer creates the 微同步 folder, its 00_收件箱 / 10_已处理 / 90_附件 subfolders or placeholder AGENTS.md / CLAUDE.md files when Obsidian starts. Clip folders are created only when a clip is actually saved, so a folder you delete stays deleted.
- Clips saved to a folder chosen in the browser extension now keep their images in an 附件 folder beside the note instead of 微同步/90_附件.
- The "Browse folders" button for choosing the clip root folder is now available to every user, so WeChat articles can be saved into a folder you already have.
